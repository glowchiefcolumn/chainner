# chaiNNer

### Node-based image processing and AI upscaling

chaiNNer is a node-based image processing application that makes AI upscaling and enhancement pipelines visual and intuitive. Chain together models, filters, and operations to build powerful image workflows.

<br>

---

## Features

| | |
|:---|:---|
| **Node Graph Editor** | Build complex image processing pipelines with drag-and-drop nodes |
| **AI Upscaling** | Run ESRGAN, Real-ESRGAN, and hundreds of community upscaling models |
| **Batch Processing** | Process entire folders of images with a single workflow |
| **GPU Accelerated** | Leverages your GPU via ONNX, PyTorch, and NCNN backends |
